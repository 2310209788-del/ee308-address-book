# EE308FZ 通讯录
双人极限编程作业。截止时间为北京时间 2026-11-17 23:59。

## 功能清单
- 收藏联系人并快速查看收藏列表。
- 为同一个联系人保存多条联系方式。
- 导出 Excel，每行一个联系人，并能从相同格式导入。

## 协作计划（待两位成员确认）
- 成员一负责联系人编辑、收藏和列表界面。
- 成员二负责 Excel 导入导出和往返验证。
- 各自在功能分支开发，通过 Pull Request 审阅后合并。每人用自己的 GitHub 账号提交实际完成的代码。
- 每位成员记录 PSP 计划和实际用时，保留运行截图、演示视频和 Git 提交记录。
